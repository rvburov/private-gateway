## Что проверить владельцу на своих устройствах

### Подключения устройств

Для **каждого нового устройства** создайте отдельный профиль в панели, нажмите «Применить конфигурацию» и убедитесь, что версии совпали. Импортируйте профиль в клиент, поддерживающий VLESS + REALITY + Vision. В списке ниже отмечайте результат отдельно для каждого фактически используемого типа устройства; там, где проверка не нужна или устройства нет, пишите «не применяется».

- [ ] **Другие клиенты Windows и полный туннель:** Hiddify в системном прокси с Chrome проверен выше. Отдельно испытать v2rayN и Throne (бывший NekoRay), а также приложения вне браузера и TUN с диагностикой домашнего IP. Ожидаемый IPv4 при успешном подключении — `162.35.172.6`.
- [ ] **ПК и ноутбук с macOS:** в установленном клиенте с VLESS + REALITY + Vision импортировать URI или конфигурацию sing-box, подключиться и проверить внешний IPv4. Успех на Windows не заменяет эту проверку.
- [ ] **ПК и ноутбук с Linux:** импортировать sing-box JSON либо Mihomo YAML, проверить соединение из браузера через локальный proxy и, если нужен весь трафик устройства, отдельно проверить TUN-режим. Локальный тест ядра не подтверждает эту установку.
- [ ] **Телефон и планшет с Android:** импортировать URI или QR в актуальный v2rayNG, затем при необходимости в NekoBox; проверить IPv4 на Wi-Fi и мобильной сети там, где они доступны. Android ещё не проверялся физически.
- [ ] **iPhone и iPad:** результат iPhone + Hiddify по LTE отмечен выше. Отдельно проверить Hiddify на Wi-Fi и iPad, если он есть, и импорт URI в нужные альтернативные клиенты, например Streisand или Shadowrocket. Успех одного приложения и сети не подтверждает другие.
- [ ] **Другие используемые устройства и ОС:** выбрать доступный для них клиент/ядро с VLESS + REALITY + Vision, импортировать URI или файл из панели и проверить реальный трафик. Для отсутствующего у владельца типа устройства пометить «не применяется», а не `[x]`. Для каждого планируемого клиента записать результат в [матрице](clients.md).

Если нужен полный VPN, сначала настроить TUN/VPN-режим, затем убедиться на внешнем сайте и в приложениях вне браузера, что домашний IP не виден; на проверенном ПК Windows переключение Hiddify в «VPN» как раз показало домашний IP.
